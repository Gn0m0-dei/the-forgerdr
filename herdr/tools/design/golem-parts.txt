GOLEM PARTS · 12x12 and 8x8 grids read from design/forgnome.pen (03 Sprites, GOLEMS section)
==========================================================================================

How the sprites are built in the file
-------------------------------------
Every golem is a `frame` named "Golem" (layout none) holding one `path` child per
colour layer, named "px <letter>". Each path has viewBox [0,0,12,12] (Iron, Stone) or
[0,0,8,8] (Clay) and a geometry made of 1-pixel-high run rectangles
(`M x y h w v1 h-w z`), so the frame is scaled by whole numbers with no filtering.
The paths stack in child order and a later layer covers an earlier one:

  Iron   px K, px G, px e, px g, px r
  Clay   px K, px e, px G, px r
  Stone  px K, px v, px G, px e, px g, px r   (CRACKED has no px v: the moss fell off)

Sizes on the canvas: 03 Sprites draws Iron and Stone at 72x72 and Clay at 48x48
(6x; Clay sits 24 px lower so the feet line up). Tree rows draw Iron at 24x24 and Clay
at 16x16 (2x); the golem lanes draw Clay at 16x16 inside a 24x24 box aligned to the
bottom centre, and Stone at 24x24 (2x).

Roles: IRON = main Claude session, CLAY = subagent, STONE = agent-team teammate.

Not in the design file: two sessions get golems of their own, drawn on Iron's body at
Iron's size, with Iron's chest (where the crucible fills), moods and cracks:
  REVIEWER  a session reviewing a pull request: its right hand holds a magnifying
            lens up beside its eye, a round shaded-iron rim around the glass, so it
            reads on a dark theme too, where the outline does not show
  WARDEN    a session triaging a security review: a visor, its two eyes one toned
            slit, and a crimson shield on its left arm, three columns wide so it
            ends in a point

Moods and the agent states that use them (Task 29's `golem_mood`):
  FORGING  Working
  WAITING  NeedsPermission, NeedsInput
  DONE     Done
  CRACKED  Failed
  IDLE     Ready, Ended, Unknown   (new: eyes and core unlit, $fg-muted)

Only the eye layer (px e) and the core layer (px r) change colour between moods; the
CRACKED mood also changes the shape (crack pixels in the outline colour).

Grid letters (left column), the layer they come from (middle) and the colour (right).
Every letter is exactly one colour, so two moods that differ only in colour still give
different grids. Lower-case letters are the shade of the upper-case body letter.

  .  transparent
  O  outline                  px K           #0d0d12   ($ink)
  I  iron body                px G (Iron)    #8a94a3
  i  iron shade               px g (Iron)    #5f6875
  C  clay body                px G (Clay)    #c0703f
  S  stone body               px G (Stone)   #9b9484
  s  stone shade              px g (Stone)   #6e695c
  V  moss (stone)             px v           #6f8f4a
  L  lens glass (reviewer)    none           #7fd1e0
  X  shield (warden)          none           #d1394b
  x  shield shade (warden)    none           #9e2638
  R  lit core (FORGING)       px r           #ffb347   ($ember-hot)
  U  dead core (CRACKED)      px r           #3a3a44
  W  working tone             px e, px r     token sem-working
  N  needs-you tone           px e, px r     token sem-needs
  D  done tone                px e, px r     token sem-done
  F  failed tone              px e           token sem-failed
  Q  quiet tone (IDLE)        px e, px r     token fg-muted

W, N, D, F and Q are theme tokens (WidgetTheme), not fixed art colours: they follow the
terminal theme like the chips do. The other letters are fixed art colours.

Rows are y = 0..11 (or 0..7) top to bottom, columns x = 0..11 (or 0..7) left to right.

PALETTE
-------
Fixed art colours (hex, as found on the sprite paths):

  O  outline        #0d0d12   ($ink)
  I  iron body      #8a94a3
  i  iron shade     #5f6875
  C  clay body      #c0703f
  S  stone body     #9b9484
  s  stone shade    #6e695c
  V  moss           #6f8f4a
  R  lit core       #ffb347   (same value as $ember-hot)
  U  dead core      #3a3a44   (same value as the gnome sheet's metal)
  L  lens glass     #7fd1e0   (same value as the gnome sheet's lens)
  X  shield         #d1394b   (same value as the crimson hat)
  x  shield shade   #9e2638   (same value as the crimson hat's shade)

Theme tokens (values per terminal theme in forgnome.pen: forge / gruvbox / dracula):

  W  sem-working    #5fd7d7 / #8ec07c / #8be9fd
  N  sem-needs      #f5b43c / #d79921 / #f1fa8c
  D  sem-done       #f2de6e / #fabd2f / #e5a93b
  F  sem-failed     #f0607a / #ff6952 / #ff6e6e
  Q  fg-muted       #99948e / #a39981 / #a5a6a7

Note on IDLE: fg-muted sits close to the iron and stone body greys, so on Iron and
Stone the unlit eyes and core nearly merge into the body (the golem reads as a still,
faceless statue); on Clay they show as grey eyes on the outline row and a grey core.
