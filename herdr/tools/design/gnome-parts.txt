GNOME PARTS · 16x16 grids read from design/forgnome.pen (03 Sprites, PARTS section)
=====================================================================================

How the sprites are built in the file
-------------------------------------
Every gnome head is a `frame` (layout none, 80x80 on the sheet, 32x32 in tabs,
48x48 in the sidebar, 128x128 in the setup) holding one `path` child per palette
colour, named "px <letter>". Each path has viewBox [0,0,16,16] and a geometry made
of 1-pixel-high run rectangles (`M x y h w v1 h-w z`), so the frame is scaled by
whole numbers with no filtering. The paths stack in child order: K (outline) first,
then hat, band, skin, skin shade, eyes, nose, beard, beard shade. A later layer
covers an earlier one, which is why eye and brow pixels live in the E layer and the
skin layer leaves holes under the default brows. Parts are NOT separate nodes: each
head on the sheet is a full composite, so the grids below are composites too, and a
part is the difference against the default head (HAT POINTED / BEARD FULL /
EYES PLAIN / no accessory, which are all the same head).

Grid letters (left column) and the layer name they come from (right column):

  .  transparent
  O  outline              px K   #0d0d12
  S  skin                 px S   #f3c7a3
  s  skin shade (extra)   px s   #d9a27e
  C  cheek / nose         px N   #e8a48a
  W  beard white          px W   #f2f2f2
  w  beard shade (extra)  px w   #c9c9d1
  E  eye (and brows)      px E   #0d0d12
  H  hat colour           px H   per hat colour, see palette
  h  hat shade (extra)    px h   per hat colour, see palette
  B  band                 px B   #8b5a2b
  M  metal (headphones)   px p   #3a3a44
  L  lens (goggles)       px L   #7fd1e0
  G  gold (monocle rim)   px Q   #e5a93b

Rows are y = 0..15 top to bottom, columns x = 0..15 left to right.

PALETTE
-------
Fixed colours (hex, as found on the sprite paths; the file's variables also define
$ink #0d0d12, $skin #f3c7a3 and $beard #f2f2f2 with the same values):

  O  outline        #0d0d12   ($ink)
  E  eye / brows    #0d0d12   ($ink)
  S  skin           #f3c7a3   ($skin)
  s  skin shade     #d9a27e
  C  cheek / nose   #e8a48a
  W  beard white    #f2f2f2   ($beard)
  w  beard shade    #c9c9d1
  B  band           #8b5a2b
  M  metal          #3a3a44
  L  lens           #7fd1e0
  G  gold (monocle) #e5a93b   (same value as $forge-gold)

Hat colours (H = hat, h = hat shade). These are NOT variables in forgnome.pen: each
sprite carries the hex directly on its "px H" / "px h" paths. Values read from the
HAT AND APRON COLOURS row of 03 Sprites:

  crimson  H #d1394b   h #9e2638   (the default on every other sprite)
  forest   H #3f8f4f   h #2b6337
  indigo   H #5b6be0   h #3b47a8
  ochre    H #d19a39   h #9e7026
  teal     H #2f9e9a   h #1f6e6b
  plum     H #9b4bc4   h #6e3390

The apron is not drawn on the 16x16 head; the sheet says it takes the hat colour.
